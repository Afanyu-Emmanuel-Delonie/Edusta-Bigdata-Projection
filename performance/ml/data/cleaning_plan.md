
# Cleaning Plan

This dataset was generated and cleaned using AUCA rules:

- 30% assignment
- 30% midterm
- 40% final
- Attendance below 25% results in exam denial → automatic Fail
- Pass mark = Total score ≥ 50

Columns:
- student_id
- assignment_score
- midterm_score
- final_score
- attendance_percent
- total_score
- exam_denied
- pass_fail

All values were kept within range 0–100.
