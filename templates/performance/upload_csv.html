CSV Format Requirements

Your CSV file must contain the following columns:

  • •
    Student_ID: 5-digit student identification number
  • •
    First_Name: Student's first name
  • •
    Last_Name: Student's last name
  • •
    Department: Student's department
  • •
    Course: Course code (e.g., CS101)
  • •
    Group: Group or section name
  • •
    Semester: Semester name (e.g., "Fall 2024")
  • •
    Score: Numerical score (0-100)

Optional columns: Grade, Performance_Status, Ranking

Note: If Grade and Performance_Status are not provided, they will be calculated automatically based on the score.
